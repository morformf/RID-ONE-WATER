# RID ONE WATER — UI 1.3

ปรับ Dashboard ให้ใกล้เคียงรูปตัวอย่าง: แถบหัวเว็บสีน้ำเงิน, เมนูแนวนอน, KPI, แผนที่, กราฟ, ข่าวสถานะ, ปุ่มแจ้งเหตุ และการ์ดบริการ

## ติดตั้ง

```bash
pip install -r requirements.txt
streamlit run app.py
```

## อัปเดตเว็บไซต์เดิมบน Streamlit Cloud

1. ใช้ไฟล์ทั้งหมดใน ZIP อัปโหลดเข้า Repository `morformf/RID-ONE-WATER` โดยให้ `app.py` อยู่ที่ root
2. สำคัญ: ต้องคงโฟลเดอร์ `data/` ที่มี CSV ทุกไฟล์ไว้ด้วย
3. Commit การเปลี่ยนแปลง และเปิดลิงก์ Streamlit เดิมอีกครั้ง
4. ไม่มีการเปลี่ยนแปลงข้อมูลทางการ และแบบฟอร์มรับแจ้งเหตุยังเป็นแบบทดลองเท่านั้น

> หมายเหตุ: หน้าตาอิงแนวทางของภาพตัวอย่าง แต่ไม่ใช่การแปลงรูปเป็นหน้าเว็บตรงพิกเซลต่อพิกเซล ส่วนของ GUI และการ์ดจะปรับตามอุปกรณ์
