# RID ONE WATER 1.7 – Navigation & Feedback (Demo)

อัปเดตจากไฟล์โปรเจกต์เวอร์ชัน 1.6 ที่เคยจัดทำไว้

## เพิ่มอะไร
- ปุ่ม 🏠 กลับหน้าหลัก ในทุกหน้าย่อย รวมทั้งเมนูเจ้าหน้าที่
- บอกชื่อหน้าปัจจุบัน
- แสดงจำนวนเรื่องทดลองและข้อความเตือนบนหน้า จัดการเรื่องแจ้ง (สาธิต) ว่าเก็บข้อมูลเฉพาะ session

## วิธีอัปเดต
แทนที่ `app.py` ใน GitHub ด้วยไฟล์จาก ZIP นี้และ Commit changes; ไม่ต้องเปลี่ยนไฟล์ข้อมูลอื่น ๆ เมื่อ repository อยู่บนเวอร์ชัน 1.6 เดียวกัน

## ข้อจำกัดที่สำคัญ
- **ยังไม่มีฐานข้อมูลร่วม** ข้อมูลจากคนละอุปกรณ์จะไม่ปรากฏร่วมกัน
- **ยังไม่มีระบบล็อกอินเจ้าหน้าที่** อย่าใส่ข้อมูลส่วนบุคคลจริงหรือเปิดใช้เป็นระบบรับแจ้งเหตุทางการ
- สำหรับการรับความคิดเห็นจริงควรเพิ่มฐานข้อมูลถาวร, authentication, จำกัดสิทธิ์, anti-spam, audit log, PDPA
