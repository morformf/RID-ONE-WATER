# RID ONE WATER — Full Integrated Demo 1.1

ระบบต้นแบบ Streamlit ที่รวมหน้าสาธิตข้อมูลน้ำหลายประเภท **ในเว็บไซต์เดียว** พร้อมข้อมูลตัวอย่างและตัวเชื่อม API สาธารณะ (ต้องทดสอบการเชื่อมต่อกับปลายทางจริงเมื่อออนไลน์)

> **สำคัญ:** ข้อมูลเริ่มต้นทุกชุดเป็นข้อมูลสมมติ (`source=demo`) ใช้เพื่อแสดงหน้าจอเท่านั้น ไม่ใช่ข้อมูลสถานการณ์จริง แผนระบายจริง การเตือนภัยอย่างเป็นทางการ หรือระบบรับเรื่องของกรมชลประทาน

## เมนูที่มี

1. **ภาพรวมและ GIS**: แผนที่สถานี คัดกรองลุ่มน้ำ จังหวัด และประเภทสถานี พร้อมสถานะความใหม่ของข้อมูล
2. **สถานีและกราฟ**: ดูระดับน้ำ อัตราการไหล และฝน ย้อนหลังหลายสถานี
3. **ข้อมูลฝน**: แผนที่สถานีฝน กราฟรายวัน สรุปสถานีและดาวน์โหลด CSV
4. **เขื่อน/อ่างเก็บน้ำ**: ตาราง API สาธารณะ RID (เฉพาะกรณีดึงสำเร็จ); Rule Curve; แผนระบายรายวันที่แก้ไขได้; จำลองสมดุลน้ำ; แผนบริหาร **ฤดูฝน** และ **ฤดูแล้ง**
5. **ประตูระบายน้ำ**: ข้อมูลอาคารและการระบายจากไฟล์ที่มีสิทธิ์นำเข้า (เริ่มต้นเป็น demo)
6. **คุณภาพน้ำ**: พารามิเตอร์และสถานะคุณภาพน้ำจากไฟล์ที่มีสิทธิ์ (เริ่มต้นเป็น demo)
7. **ผังน้ำและทิศทางการไหล**: โครงข่ายการไหลเชิงแนวคิดสำหรับสาธิต ไม่ใช่แผนที่ภูมิศาสตร์จริง
8. **แจ้งเตือน**: ข้อมูลไม่อัปเดต และเกณฑ์สาธิตระดับน้ำ Q ฝน
9. **ประชาชนแจ้งเหตุ/ข้อเสนอแนะ**: ฟอร์มทดลองพร้อมเลขอ้างอิงและติดตามสถานะภายใน session (ไม่ได้แจ้งถึงกรมจริง)
10. **จัดการเรื่องแจ้ง (สาธิต)**: เจ้าหน้าที่จำลองการเปลี่ยนสถานะเรื่องแจ้ง; ยังไม่มีการยืนยันตัวตน
11. **นำเข้าข้อมูล**: CSV/XLSX ทะเบียนสถานี ค่าตรวจวัด Rule Curve แผนระบาย ประตูระบายน้ำ คุณภาพน้ำ
12. **ส่งออกรายงาน**: Excel และ CSV (ไม่ส่งออกช่องทางติดต่อหรือพิกัดผู้แจ้ง)

## ติดตั้งและรัน

ต้องใช้ Python 3.11 หรือ 3.12 และอินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจครั้งแรก

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

เปิด `http://localhost:8501` ในเบราว์เซอร์

**รันแบบง่าย Windows:** ดับเบิลคลิก `run_windows.bat` (ต้องติดตั้ง Python และเชื่อมต่ออินเทอร์เน็ต)

### ใช้งานบน Streamlit Community Cloud

1. สร้าง GitHub repository และอัปโหลดโฟลเดอร์นี้ทั้งหมด (โครงสร้างไฟล์ต้องอยู่ระดับราก)
2. ที่ Streamlit Community Cloud เลือก **Create app** และเลือก repository นี้
3. ระบุ Main file path เป็น `app.py` และ Deploy
4. ก่อนเผยแพร่ให้ประชาชนจริง **ปิดเมนูรับเรื่อง/จัดการเรื่องแจ้ง** หรือพัฒนาระบบล็อกอิน, ฐานข้อมูล, สิทธิ์ข้อมูล, กฎหมายคุ้มครองข้อมูล และกระบวนการรับเรื่องอย่างเป็นทางการก่อน

## รูปแบบแผนระบายรายวัน

`data/release_plan_demo.csv` ใช้คอลัมน์

```csv
date,inflow_cms,release_cms
2026-11-23,140,90
2026-11-24,150,100
```

การคำนวณ: `storage_next (ล้าน ลบ.ม.) = storage_current + (inflow_cms - release_cms) × 0.0864` ต่อวัน; สมมติเป็นค่าเฉลี่ยรายวัน ไม่รวมการระเหย การรั่วซึม หรือทางระบายอื่นที่ไม่ได้ระบุ และตัดค่าภายในความจุอ่าง จึงไม่ใช่แบบจำลองทางชลศาสตร์หรือแผนปฏิบัติการ

## ข้อมูลจริง

ตัวเชื่อม `connectors.py` มีปุ่มเรียกข้อมูลอ่างจาก API สาธารณะของกรมชลประทาน หากเรียกไม่ได้จะแจ้งข้อผิดพลาดและไม่แอบใช้ข้อมูล demo แทนข้อมูลจริง

- ค่าตรวจวัดรายสถานี ฝน ประตูระบายน้ำ และคุณภาพน้ำ: ยังเป็น demo หรือไฟล์ที่ผู้ใช้มีสิทธิ์นำเข้า
- ระดับน้ำและตำแหน่งแผนที่: พิกัดของ demo ไม่ใช่ทะเบียนสถานีอย่างเป็นทางการ
- แผนงานด้านฤดูฝน/ฤดูแล้ง: เป็นแนวคิดประกอบการนำเสนอ ต้องใช้เกณฑ์จริงที่กรมอนุมัติก่อนใช้งาน

## ความปลอดภัย/ข้อจำกัด

- ไม่มีฐานข้อมูลถาวร ข้อมูลอัปโหลดและเรื่องแจ้งอยู่ใน `st.session_state` ของแต่ละ session เท่านั้น
- ไม่มีล็อกอินหรือกำหนดสิทธิ์จริง; ห้ามใช้กับข้อมูลส่วนบุคคลจริงหรือเปิดหลังบ้านสู่สาธารณะ
- รูปที่แนบในแบบฟอร์มมีการตรวจขนาด แต่ยังไม่มีระบบจัดเก็บ ตรวจไวรัส หรือกลั่นกรอง
- ควรเพิ่ม API gateway, audit logs, data lineage, time-series DB, GIS station registry และ PDPA compliance ก่อนใช้จริง
- อาจต้องทดสอบ endpoint และโครงสร้าง JSON ของ RID API ใหม่เมื่อเชื่อมกับปลายทาง

