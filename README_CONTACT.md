# RID ONE WATER UI 1.4 — เพิ่มข้อมูลติดต่อกรมชลประทาน

## สิ่งที่เพิ่ม
- เมนู "☎️ ติดต่อกรมชลประทาน" ในเมนูเพิ่มเติม
- กล่องสายด่วน 1460 และปุ่มเข้าหน้าติดต่อบน Dashboard
- Footer ข้อมูลติดต่อปรากฏทุกหน้า
- ปุ่มโทรศัพท์ อีเมล เว็บไซต์ทางการ และแผนที่

## วิธีอัปเดต Streamlit Cloud
1. เปิด GitHub Repository `morformf/RID-ONE-WATER`
2. เปิด `app.py` และอัปเดตเนื้อหาด้วยไฟล์ `app.py` เวอร์ชันนี้ โดยไม่ลบไฟล์ Python และ data อื่น ๆ
3. Commit changes และรีโหลดเว็บไซต์ https://rid-one-water.streamlit.app/
